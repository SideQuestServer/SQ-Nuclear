# Contributing to SQ-Nuclear

Thanks for wanting to help!

Please get in touch with SideQuestChris on Discord before your first commit: https://discord.gg/9DUcANyAvV

You will get the contribution rules there.

Contributions work through a fork and a pull request against the `pre-release` branch.

Contributions are released under the MIT license of this repository. Everyone whose contribution is used is listed in [CONTRIBUTORS.md](CONTRIBUTORS.md).
